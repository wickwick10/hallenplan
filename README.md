# Hallenplan

Trainingsplaner für Handball: Pläne nach Altersstufe (F-Jugend bis Aktive), Niveau und taktischer Ausrichtung, mit Übungsbibliothek, Spielsystemen und Krafttraining.

Lokal ansehen: `index.html` im Browser öffnen.

Prüfen:
```
npm install
npx playwright install chromium
npm run check   # Inhalte
npm test        # Oberfläche
```
